# Maluma Memes - Plataforma de Fans

**Una plataforma moderna y divertida para la comunidad de fans de Maluma, donde el entretenimiento y los memes se unen para celebrar al Pretty Boy.**

---

## Descripción del Proyecto

**Maluma Memes** es una aplicación web de una sola página (SPA) diseñada para proporcionar entretenimiento y crear una comunidad vibrante alrededor de los memes y la cultura de Maluma. La plataforma ofrece una experiencia interactiva donde los fans pueden disfrutar de contenido dinámico, frases icónicas del artista y conectarse con otros seguidores.

### Necesidad que Resuelve

- **Entretenimiento**: Proporciona una fuente constante de contenido divertido y relevante para los fans
- **Comunidad**: Crea un espacio digital donde los seguidores pueden compartir y disfrutar de memes
- **Interactividad**: Ofrece una experiencia dinámica con contenido que cambia constantemente
- **Accesibilidad**: Plataforma web moderna accesible desde cualquier dispositivo

## Instalación y Ejecución

### Prerrequisitos
- Node.js (versión 16 o superior)
- NPM (generalmente incluido con Node.js)

### Pasos de Instalación

1. **Clonar o descargar el proyecto**
   ```bash
   # Si tienes el código fuente, navega al directorio
   cd "c:\Users\PC\Downloads\Proyecto Katherine Daniela Quintero Paez"
   ```

2. **Instalar dependencias**
   ```bash
   npm install
   ```

3. **Iniciar servidor de desarrollo**
   ```bash
   npm run dev
   ```

4. **Abrir en el navegador**
   - La aplicación estará disponible en `http://localhost:5173`

## Estado actual del proyecto

Se realizó la configuración inicial y organización del proyecto desarrollado con React + Vite.

# Cambio de concepto y rediseño de la aplicación

## Evolución de la idea principal

La aplicación pasó de ser una página informativa/de entretenimiento basada en memes, a convertirse en un ecosistema interactivo donde el usuario puede participar, personalizar su experiencia y realizar diferentes actividades dentro de la plataforma.

La nueva propuesta incluye funcionalidades orientadas a la interacción del usuario, gamificación y personalización.

---

# Nuevas funcionalidades planteadas

## 1. Ecosistema interactivo

La página actualmente está siendo desarrollada como un espacio donde el usuario podrá:

* Participar en diferentes minijuegos.
* Obtener créditos mediante la interacción dentro de la plataforma.
* Utilizar los créditos obtenidos dentro del mismo ecosistema.
* Personalizar su experiencia dentro de la aplicación.

---

## 2. Sistema de perfil y personalización

Se agregó la idea de implementar un perfil de usuario donde será posible:

* Crear y editar un avatar personalizado.
* Modificar características visuales del usuario dentro de la plataforma.
* Guardar la información asociada al perfil.

Esta funcionalidad busca generar una experiencia más personalizada e interactiva.

---

## 3. Sistema de créditos y compras

Se plantea la implementación de un sistema interno donde:

* Los usuarios podrán ganar créditos mediante los minijuegos.
* Los créditos podrán ser utilizados dentro de la misma página.
* Existirá un sistema de compra y gasto interno para elementos disponibles dentro de la aplicación.

Este sistema permitirá integrar una mecánica de recompensa y progresión del usuario.


### Objetivo del cambio:

* Evitar subir archivos innecesarios al repositorio remoto.
* Excluir dependencias instaladas localmente (`node_modules`).
* Evitar subir archivos generados automáticamente por el proceso de compilación (`dist`).
* Proteger archivos con variables de entorno o información sensible (`.env` y `.env.local`).

# Organización de componentes React

Se mantiene una estructura modular dentro de la carpeta `src`, separando responsabilidades y facilitando el mantenimiento del código.

## components/

Contiene componentes reutilizables de la interfaz.

Ejemplos:

* Header.
* Menu.
* Componentes visuales generales.

## pages/

Contiene las páginas principales de la aplicación.

## layouts/

Contiene estructuras generales utilizadas para organizar la presentación de las diferentes vistas.

## router/

Contiene la configuración del sistema de navegación mediante React Router.

## context/

Destinado al manejo del estado global de la aplicación mediante Context API.

## data/

Destinado al almacenamiento de información estática utilizada por los componentes.
